# Smart Registration via LINE OA

ระบบรับภาพถ่ายหน้าสมุดจดบันทึกการทำงานของห้องปฏิบัติการสวนหัวใจ (Cath Lab) ผ่าน LINE OA เพื่อนำมาสกัดข้อมูลรายเคสด้วยเทคโนโลยี Document AI แบบคงโครงสร้างตาราง พร้อมจัดระเบียบข้อมูลด้วย Gemini LLM โดยมีระบบตรวจสอบและแก้ไขข้อมูลผ่านหน้าเว็บแอปพลิเคชัน (LIFF) ก่อนบันทึกลง Google Sheet อย่างเป็นระบบ

## Objective

- ลดภาระการคีย์ข้อมูลซ้ำซ้อนจากสมุดจดเข้าสู่ระบบดิจิทัล
- ลดความผิดพลาดจากการอ่านลายมือ ด้วย AI และการทบทวนโดยเจ้าหน้าที่ (Human-in-the-loop)
- ป้องกันการหลุดรอดของข้อมูลส่วนบุคคล (PHI) ก่อนส่งไปวิเคราะห์บน Cloud
- จัดเก็บข้อมูลอย่างเป็นระบบใน Google Sheet เพื่อง่ายต่อการค้นหา จัดทำรายงาน และส่งมอบให้แผนกบัญชี

## Workflow ปัจจุบัน

1. **Input**: เจ้าหน้าที่ส่งภาพถ่ายหน้าสมุดจด (1 ภาพมีได้หลายเคส) ผ่าน LINE OA
2. **AI Processing Pipeline**:
   - **Table Extraction**: Google Cloud Document AI (Form Parser) ถอดรหัสภาพลายมือให้ออกมาเป็นโครงสร้างตาราง ป้องกันปัญหาข้อมูลกระโดดข้ามคอลัมน์
   - **PHI Masking**: ระบบทำการตรวจจับและ Mask ข้อมูลส่วนบุคคล (เช่น ชื่อ-นามสกุล, เลขประจำตัวผู้ป่วย (HN/AN), และเลขบัตรประชาชน) ออกจากข้อความ
   - **Data Structuring**: Gemini 1.5 Flash ประมวลผลข้อความที่ถูก Mask เพื่อจัดหมวดหมู่คำ เติมคำ และปรับแก้ตัวย่อทางการแพทย์ให้อยู่ในรูปแบบ JSON Array มาตรฐาน
   - **Validation**: โค้ด Backend สวมข้อมูลที่ถูก Mask กลับเข้าที่เดิมแบบแยกตามแถว (Row-by-Row) และตรวจสอบรูปแบบ (เช่น รูปแบบวันที่ หรือรูปแบบ CCN)
3. **Review (Human-in-the-loop)**: เจ้าหน้าที่ตรวจสอบความถูกต้องของข้อมูลผ่าน LINE LIFF App และทำการปรับจำนวนอุปกรณ์ที่ใช้ (Equipment) ด้วยตนเอง
4. **Storage**: บันทึกข้อมูลที่สมบูรณ์และได้รับการยืนยันแล้วลง Google Sheet (พร้อมระบบตรวจสอบและปฏิเสธข้อมูลที่ใส่เลข CCN ซ้ำซ้อน)
5. **Output**: ข้อมูลพร้อมถูกนำไปใช้พิมพ์รายงานส่งบัญชี หรือใช้ในระบบ Dashboard ดูสถิติ

## Components

- **LINE OA & LIFF**: ช่องทางสำหรับรับภาพ และ UI สำหรับตรวจสอบ/แก้ไขข้อมูล
- **Google Cloud Document AI**: เครื่องมือสำหรับสกัดข้อความพร้อมรักษาโครงสร้างตารางจากภาพ
- **Gemini 1.5 Flash**: LLM หลักสำหรับจัดหมวดหมู่และตีความข้อความทางการแพทย์
- **Google Sheet**: ฐานข้อมูลศูนย์กลางสำหรับเก็บระเบียนคนไข้และดึงข้อมูลมาออกรายงาน
